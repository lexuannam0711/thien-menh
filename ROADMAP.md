# Thần Mệnh — Roadmap

## Current

- Core campaign, RPG catalog, boss framework, audio, pause/game-over and release documentation integrated.
- Build and focused self-checks passing.

## Remaining release gates

1. Wire required NPC/enemy/elite/dungeon content and full quest chains into actual gameplay.
2. Full browser playthrough on the release build.
3. Touch/mobile acceptance on representative physical devices.
4. FPS, heap and 30-minute stability measurement.
5. Reconcile runtime findings, then sign `RELEASE_CHECKLIST.md`.

## Out of scope

Backend, accounts, analytics, paid hosting, New Game+ and post-release expansion.
